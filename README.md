## Computational pathology

Previously **co-founder & CTO at [Enso Biosciences](https://ensohealth.ai)**. I worked on **EnsoPurity**, a PyTorch tumor-purity estimator using distribution-pooling multiple-instance learning over frozen **Virchow v1** embeddings, and co-developed preprocessing, tiling, and embedding pipelines for **40,000+ gigapixel pathology images**.

I also collaborated on **[Enso Atlas](https://www.kaggle.com/competitions/med-gemma-impact-challenge/writeups/Enso-Atlas)**, a pathology viewer combining Google Path-based image-similarity retrieval, downstream prediction models, and MedGemma-assisted report drafting. The project received a **Google Honorable Mention in the Kaggle MedGemma Impact Challenge**.
